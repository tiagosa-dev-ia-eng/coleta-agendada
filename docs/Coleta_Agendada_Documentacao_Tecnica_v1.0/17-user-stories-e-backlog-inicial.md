# 17 — User Stories e Backlog Inicial

## Paciente

### US-001
Como paciente, quero solicitar uma coleta pelo site para não precisar ligar para o laboratório.

### US-002
Como paciente, quero solicitar pelo WhatsApp para realizar o processo de forma conversacional.

### US-003
Como paciente, quero anexar meu pedido médico para que os exames sejam identificados.

### US-004
Como paciente, quero receber um orçamento validado para decidir se aprovo.

### US-005
Como paciente, quero acompanhar o status da solicitação.

## Atendente / operação

### US-006
Como atendente, quero revisar o rascunho gerado pela IA para evitar que informações incorretas sejam enviadas.

### US-007
Como atendente, quero enviar o orçamento final após revisão.

## Farmácia

### US-008
Como farmácia, quero visualizar minha agenda de coletas.

### US-009
Como farmácia, quero consultar minhas comissões.

## Técnico

### US-010
Como técnico, quero visualizar minha agenda.

### US-011
Como técnico, quero fazer check-in e check-out.

### US-012
Como técnico, quero marcar uma coleta como realizada.

### US-013
Como técnico, quero consultar minhas comissões.

## Revendedor

### US-014
Como revendedor, quero cadastrar farmácias.

### US-015
Como revendedor, quero cadastrar técnicos.

### US-016
Como revendedor, quero acompanhar indicações e comissões.

## Laboratório

### US-017
Como laboratório, quero acompanhar todas as coletas do meu escopo.

### US-018
Como laboratório, quero acessar dashboard e relatórios.

### US-019
Como laboratório, quero administrar regras de comissão.
